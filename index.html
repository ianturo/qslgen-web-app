📖 Manual de usuario
Abriste la página como archivo local. La consulta a QRZ y el envío de correos necesitan el servidor: ejecuta python server.py y entra a http://localhost:8000.
1. Archivo ADIF
Arrastra aquí tu archivo .adi / .adif o haz clic para elegirlo

3. Diseño de la QSL

4. QRZ.com

Se consulta xmldata.qrz.com/xml/?s=SESSION;callsign=CALL. El correo solo lo entrega QRZ si tu suscripción XML lo incluye.

5. Envío por Gmail

Usa {NOMBRE} para el nombre que devuelve QRZ y {QSOS} para la lista de contactos.

6. Guardar / cargar configuración

Guarda en un archivo los datos de tu estación, el diseño de la QSL (fondo, logos, iconos y textos) y la configuración del correo, para cargarlos en otro computador o navegador.

⚠ Quedarán sin cifrar dentro del archivo. Guárdalo en un lugar seguro y no lo compartas.⚠
